# 專案預覽站

共用的靜態網站預覽與手機測試入口。每個專案放在獨立子資料夾，方便重複部署。

## 使用方式

開啟預覽首頁，選擇要測試的網站。預覽頁會標示測試狀態；本次課表預覽新增原老師待調時段標記及手機跳轉，空堂格子保留但不顯示文字，等待手機驗收。

## 新增或更新預覽

1. 在原始專案的功能分支完成已經使用者確認的修改與檢查。
2. 將可公開的靜態網站輸出放到 `<project-slug>/`，保留相對檔案路徑。不要複製 Git 目錄、環境檔、憑證或原始私人資料。
3. 在 `previews.json` 記錄專案、來源分支、完整 commit、更新日期和預覽狀態；同步更新首頁卡片。
4. 保留清楚的預覽標示及返回首頁連結。更新 JS/CSS 時調整資源版本，避免載入舊快取。
5. 提交到此專案的 `main`，由 GitHub Pages 根目錄發佈。確認部署完成、手機可開啟且內容對應來源版本。
6. 使用者測試確認後，回到原專案合併及發佈正式版。更新預覽專案不會自動合併原專案，也不會自動同步原分支。

每個網站使用自己的子目錄，例如 `lunbei-timetable/`。新增專案時保留既有專案資料夾，避免覆蓋其他測試。

GitHub Pages 可承載靜態 HTML、CSS、JavaScript；需要後端、資料庫或登入服務的專案，需另行確認測試環境。此儲存庫與網站均公開；robots 設定只用於減少搜尋索引，並非存取限制。
